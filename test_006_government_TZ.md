# ТЗ: test_006_government

Нужно выполнить тестовое задание **«Задача 6 (ИИ правительство)»** из PDF.

## Формат выполнения

- Язык: Python
- Основной формат: Jupyter Notebook (\`.ipynb\`)
- Дополнительно можно приложить \`.py\`-версию
- Решение должно быть аккуратным и пригодным для отправки работодателю

## Что требуется сделать

1. Реализовать алгоритм, который по заданной последовательности \`rho(t)\` максимизирует итоговое одобрение \`W(T)\` с учётом всех ограничений задачи.
2. Обосновать алгоритм:
   - почему он корректен;
   - если это не строго оптимальный алгоритм, то почему он разумен и какова его логика.
3. Для параметров:
   - \`N = 10\`
   - \`T = 100\`
   - \`W(0) = 1000\`
   - \`penalty(T) = 100\`
   
   нужно оценить:
   - среднее значение \`W(T)\`;
   - стандартное отклонение \`W(T)\`;
   - вероятность досрочного отстранения.
4. Построить более осторожную стратегию так, чтобы вероятность досрочного отстранения была меньше \`0.1%\`.
   Для этой стратегии тоже нужно оценить:
   - среднее значение \`W(T)\`;
   - стандартное отклонение \`W(T)\`.
5. Отдельно разобрать случай, когда предсказание обновляется каждый день, но по-прежнему показывает значения на следующие \`N\` дней:
   - как должна измениться стратегия;
   - как это повлияет на итоговый результат.

## Требования к качеству

- Решение должно запускаться воспроизводимо от начала до конца.
- Там, где используется Monte Carlo, нужно фиксировать seed или явно описать подход к воспроизводимости.
- В ноутбуке должны быть:
  - постановка задачи своими словами;
  - описание модели;
  - код;
  - численные результаты;
  - короткие выводы по каждому подпункту.
- Комментарии должны быть полезными, но не раздутыми.
- Финальные ответы должны быть выделены явно, чтобы их можно было быстро найти.
